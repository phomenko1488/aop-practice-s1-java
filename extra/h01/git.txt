Яку з чотирьох провалених задач розв'язує git log?
Команда git log розв'язує задачу «хто» і «чому» вніс зміни, зберігаючи автора, час та описове повідомлення до кожного збереженого знімка стану.

Яку розв'язує git diff?
Команда git diff розв'язує задачу «що змінилося», наочно відображаючи порядкову різницю у вмісті файлів між двома станами чи комітами.

Яка з них не має розв'язку аж до заняття 10?
Задача «поєднання роботи» кількох людей над спільними файлами без ручної втрати даних розв'язується пізніше через гілки, операції злиття (merge) та розв'язання конфліктів.
